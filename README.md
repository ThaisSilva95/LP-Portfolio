# 📖 Sobre o Projeto

Este projeto consiste na criação de uma página de portfólio pessoal, utilizando exclusivamente HTML e CSS. O objetivo é aplicar os conceitos aprendidos no curso e desenvolver uma estrutura visual bem organizada.

# 📝 Funcionalidades e Elementos:
✔ Estruturação de layouts com CSS Grid

✔ Inserção de imagens em diversos tamanhos

✔ Botões estilizados para navegação

✔ Campos de input para formulários

✔ Uso de ícones para complementar a interface

✔ Design responsivo e bem estruturado

# 🚀 Desenvolvimento

O projeto foi criado utilizando HTML5 e CSS3, aplicando as melhores práticas de organização do código.

🔹 Principais Características:

🔹 HTML semântico para melhor acessibilidade

🔹 CSS Grid para estruturação do layout

🔹 Flexbox para organização de elementos

🔹 Estilização personalizada para botões e inputs

🔹 Responsividade para melhor experiência em diferentes dispositivos

# 📊 Resultados

Este portfólio oferece uma interface moderna e funcional, demonstrando habilidades no uso de HTML e CSS. O design foi pensado para ser limpo, organizado e adaptável a diferentes telas.
